# B-BAK Document Signing

Customized self-hosted document signing platform used by B-BAK Berlin Berufs- & Arbeitscoaching UG.

This software is based on [Documenso](https://github.com/documenso/documenso) Community Edition and contains modifications maintained by B-BAK.
